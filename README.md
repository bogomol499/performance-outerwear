# PERFORMANCE

Сайт магазина пуховиков в Москве. Главный товар — пуховик P-01, его можно покрутить в 3D прямо на первом экране.

**Сайт:** https://bogomol499.github.io/performance-outerwear/

Что есть:
- 3D-модель куртки: крутится мышкой или пальцем, рукава и ремни раскачиваются;
- каталог с фильтрами, сортировкой и корзиной, оформление заказа;
- блок «P-01 в разрезе»: при прокрутке куртка разбирается на пять слоёв;
- лукбук, таблица размеров с подбором по росту и груди, шоурум, вопросы.

Сделано на HTML, CSS и JavaScript, 3D — three.js. Фото с Unsplash, авторы указаны на сайте.

Магазин вымышленный, заказы никуда не отправляются.
