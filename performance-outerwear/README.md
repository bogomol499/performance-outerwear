# PERFORMANCE

Сайт магазина пуховиков в Москве. Главный товар — пуховик P-01: на первом экране он висит в 3D, а при прокрутке переезжает на следующий экран и разворачивается.

**Сайт:** https://bogomol499.github.io/performance-outerwear/

Что есть:
- 3D-куртка: следит за мышкой, на телефоне крутится пальцем, рукава и ремни раскачиваются;
- каталог с фильтром по категориям, карточки наклоняются за курсором, размер добавляется в корзину в один клик;
- корзина и оформление заказа с маской телефона;
- «Пять слоёв»: при прокрутке куртка разбирается на слои в 3D;
- лукбук — кольцо из фотографий, крутится прокруткой или мышкой;
- вопросы, подписка на новую партию.

Сделано на HTML, CSS и JavaScript, 3D — three.js. Фото с Unsplash, авторы указаны на сайте.

Магазин вымышленный, заказы никуда не отправляются.
