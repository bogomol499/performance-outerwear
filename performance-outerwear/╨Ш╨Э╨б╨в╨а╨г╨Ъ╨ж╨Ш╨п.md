# Как выложить на GitHub

1. github.com → **+** → **New repository** → имя `performance-outerwear` → **Public** → **Create repository**.
2. Нажмите **uploading an existing file** и перетащите всё из папки: `index.html` и папку `assets`. Потом **Commit changes**.
3. **Settings → Pages** → Branch: `main`, `/ (root)` → **Save**.
4. Через пару минут сайт откроется: https://bogomol499.github.io/performance-outerwear/

Если в репозитории уже лежит старая версия, сначала удалите старый `index.html` или просто загрузите новые файлы поверх.

Открывать `index.html` двойным щелчком не получится: браузер не даст загрузить 3D-модель с диска. Смотрите через ссылку GitHub.
